# FRP 客户端 · HA 远程接入

一个 Home Assistant 加载项，把家里的 HA 安全地接到「HA 远程接入平台」上，实现两件事：

1. **外网访问** —— 平台给你分配一个专属端口，随时随地打开就能进自己的 HA。
2. **云端自动备份** —— 把云端的备份盘通过 frp 的 stcp 隧道「拉」到家庭局域网里，
   HA 自带的自动备份直接写进去。**公网不需要开放 445 端口**。

## 安装

1. HA → **设置 → 加载项 → 加载项商店** → 右上角 **⋮ → 仓库**，添加本仓库地址。
2. 商店里找到 **FRP 客户端 · HA 远程接入**，安装。
3. 先别启动，去 **配置** 页填写参数。

## 参数从哪来

登录平台，打开 **配置指引** 页面，页面上会列出你的专属参数，复制粘贴即可。

| 选项 | 说明 |
| --- | --- |
| `server_addr` | 平台服务器的 IP 或域名 |
| `server_port` | 你的专属 frps 端口（如 10001） |
| `token` | 你的专属认证令牌 |
| `remote_port` | 你的专属外网访问端口（如 20001） |
| `smb_secret` | 备份通道密钥 |
| `ha_local_ip` | HA 的内网地址。HA OS / Supervised 保持 `127.0.0.1`；HA Container 填宿主机 IP |
| `enable_backup` | 关掉则只做外网访问，不启用备份隧道 |

## 配置备份

加载项启动成功后，在 HA 里添加网络存储：

- **设置 → 系统 → 存储 → 添加网络存储**
- 类型：`SMB / CIFS`
- 服务器地址：`172.30.32.1`
- 共享名 / 用户名：你的平台用户名
- 密码：平台「控制台」页面里的**备份密码**

然后在 **设置 → 系统 → 备份** 里打开自动备份，备份位置选择刚添加的网络存储。

> `172.30.32.1` 是 HA 内部的宿主机地址。本加载项以 `host_network` 方式运行，
> 已经把云端备份盘映射到了这个地址的 445 端口。

## 排错

- 日志里出现 `start proxy success` 说明隧道建立成功。
- 如果提示 `port already used`，说明本机 445 端口被占用（比如装了 Samba share 加载项），
  把 `smb_bind_port` 改成 1445 —— 但注意 HA 的网络存储不支持自定义端口，
  这种情况建议停用其他占用 445 的加载项。
- 加载项必须以宿主机网络运行，这是 `config.yaml` 里的 `host_network: true`，不要改。
